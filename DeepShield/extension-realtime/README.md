# DeepShield 即時防護盾（模式 B）— 安裝與展示步驟

## 1. 前置
- 後端黑窗已啟動（桌面「DeepShield 啟動」→ `http://localhost:8000/docs` 可開）
- 前端已啟動（`frontend-web` 下 `npm run dev` → `http://localhost:5173` 可開）

## 2. 載入未封裝擴充功能
1. Chrome 開 `chrome://extensions`
2. 右上開啟**開發人員模式**
3. 按**載入未封裝項目** → 選 `DeepShield/extension-realtime` 資料夾
4. 確認出現「DeepShield 即時防護盾 0.2.0」且無錯誤
5. 工具列圖釘固定它（可選）；點圖示開 popup 應顯示「後端運行中」

## 3. 展示劇本（保證不翻車版，全程約 2 分鐘）
1. 開任意網頁（例如 `https://www.youtube.com` 首頁也行，**不需要真的播放影片**）
2. 右下角應出現**盾牌**（灰色待機，可拖曳）→ 點擊展開面板
3. 按 **[模擬詐騙直播流]**（自動開始監控＋合成測試影音，不依賴頁面 `<video>`、不受 CORS 影響）
4. 約 2–4 秒後盾牌變**紅**、分數掉到 20–30、警報列出現「觸發高風險詐騙詞彙：保證獲利」等，折線圖開始波動
5. 按 **【擷取異常片段，送交深度鑑識】** → 自動開 `http://localhost:5173/?from=extension&session_id=...`
   - 正常情況：儀表板直接渲染本次攔截報告（Gauge＋時間軸＋逐字稿螢光筆）
   - 資料路徑：外掛 `POST /api/v1/session/{id}`（後端暫存 30 分鐘）→ 前端 `GET`；同時 `chrome.storage` 備份＋ bridge 腳本雙保險

## 4. 真實影片監控（進階）
1. 開一個有 `<video>` 的頁面並播放
2. 展開面板按 **[開始監控此頁面]**（同源影片可抓幀＋抓音；跨域影片音訊會被瀏覽器靜音，外掛自動降級為影像＋字幕訊號，不報錯）
3. 綠／黃／紅燈即時反映後端評分

## 5. 除錯
- 面板顯示「後端未連線」→ 黑窗沒開或 port 被佔用（啟動器會自動清 8000 舊行程）
- 盾牌沒出現→ 重新整理頁面；`chrome://extensions` 按擴充功能的「重新載入」
- 面板 F12 主控台有 `[DeepShield]` 日誌可查
