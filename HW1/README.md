# my_curl.py - Python 命令列網路請求工具

## 專案簡介
這是我在現代軟體工程課程中，利用 Python 內建套件 (`urllib`, `argparse`) 實作的輕量級命令列網路請求工具。它能夠模擬基本的 `curl` 功能，發送 HTTP 請求並抓取網頁原始碼或 API 資料，同時具備針對特定 JSON 資料（如 MLB 賽程 API）進行自動解析與排版的功能。

## 核心功能
* **抓取網頁 HTML**：發送標準 GET 請求並回傳原始碼。
* **串接 API 測試**：能順利接收並顯示伺服器回傳的 JSON 格式資料。
* **防呆機制**：遇到無效網址時，能正確捕捉錯誤並印出提示，防止程式崩潰。
* **進階化資料解析**：針對 MLB 官方賽程 API 進行特製化處理，自動過濾冗長 JSON，轉化為直覺的「客場 VS 主場 | 地點 | 狀態」純文字播報列表。

## 使用方式
開啟終端機，並在當前目錄下執行以下指令：

1. **基本網頁抓取測試：**
   ```bash
  python my_curl.py "https://statsapi.mlb.com/api/v1/schedule?sportId=1&teamId=119&date=2026-09-11" ```
