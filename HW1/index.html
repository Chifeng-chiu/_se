現代軟體工程 · 作業一

my_curl.py

以 Python 內建套件 urllib 與 argparse 實作的輕量級命令列網路請求工具，模擬基本 curl 功能，並內建 MLB 賽程 JSON 特製解析器。

專案簡介

本專案不使用任何第三方套件，僅以 Python 標準函式庫打造一個簡易的 curl 替代工具。除了發送 HTTP 請求與抓取網頁原始碼外，還具備對 MLB 官方賽程 API 回傳的冗長 JSON 進行自動解析與排版的進階功能。

開發全程透過 OpenCode 輔助完成，涵蓋：命令列參數設計、自訂 Header 與 HTTP 方法、錯誤防呆處理、以及 JSON 結構解析。

核心功能

🌐

抓取網頁 HTML

發送標準 GET 請求，直接回傳網頁原始碼。

🔗

串接 API 測試

能順利接收並顯示伺服器回傳的 JSON 資料。

🛡️

防呆錯誤處理

捕捉 HTTPError 與 URLError，印出提示而不崩潰。

📋

特製 JSON 解析

過濾冗長 MLB 賽程 JSON，轉為直覺的純文字播報列表。

命令列參數

參數 說明 範例
url 要請求的網址（必填） https://example.com
-v, --verbose 顯示請求與回應的詳細資訊（Header、狀態碼等） -v
-X, --request 指定 HTTP 方法（GET、POST、PUT、DELETE…） -X POST
-H, --header 自訂 Header，可重複多次，格式 key:value -H "User-Agent: mycurl"
-d, --data 傳送請求資料（自動設為 form-urlencoded） -d "key=value"

使用方式

① 抓取網頁原始碼

# 基本網頁抓取
python my_curl.py https://example.com

② 帶 Header 與詳細輸出

python my_curl.py -v -H "User-Agent: mycurl" https://example.com

③ 送出 POST 資料

python my_curl.py -X POST -d "name=ccc&msg=hello" https://example.com/api

MLB 賽程特製解析

抓取道奇隊比賽的官方 API，將冗長 JSON 轉成「客場 VS 主場 | 球場 | 狀態」的純文字列表。

# 抓取並解析 MLB 即時賽事（道奇隊 teamId=119）
python my_curl.py "https://statsapi.mlb.com/api/v1/schedule?sportId=1&teamId=119&date=2026-09-11" | python parse_mlb.py

# 輸出範例：
Colorado Rockies VS Los Angeles Dodgers | Dodger Stadium | Final
San Diego Padres VS Los Angeles Dodgers | Dodger Stadium | Scheduled

搭配 parse_mlb.py，逐筆走訪 dates → games 結構，取出主客隊、球場與賽事狀態，完成資料清洗與排版。

README.md 專案說明文件

原始碼重點

  • 參數解析：使用 argparse 定義 url、-v、-X、-H、-d，其中 -H 以 append 支援重複使用。
  • 請求建構：解析 -H 為 dict，有 -d 時自動補上 Content-Type: application/x-www-form-urlencoded。
  • Verbose 模式：以 > 輸出請求、< 輸出回應，模擬 curl 的 -v 顯示格式。
  • 錯誤防呆：分別捕捉 HTTPError（4xx/5xx）與 URLError（無法連線），寫入 stderr 並回傳非零結束碼。
