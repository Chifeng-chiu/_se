從零開始的 Python 命令列之旅：my_curl 實作紀錄

現代軟體工程課程紀錄，使用 OpenCode 輔助開發一個輕量級的網路請求工具。

Phase 1: 基礎網頁抓取

首先，我讓程式能夠送出最基本的 GET 請求，成功抓回了 example.com 的 HTML 原始碼。

python my_curl.py https://example.com

Phase 2: 實戰應用 - 抓取 MLB 道奇隊賽程

為了測試進階功能，我使用了 MLB 官方的 API，並透過 OpenCode 修改程式碼，將原本雜亂的 JSON 資料，自動轉換成易讀的賽程播報列表。

python my_curl.py "https://statsapi.mlb.com/api/v1/schedule?sportId=1&teamId=119&date=2026-09-11"
