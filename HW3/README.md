#  NBA Tracker

以 **Python 標準函式庫 + Tkinter** 實作的 NBA 桌面追蹤工具，資料來自 **ESPN 公開 API**（免費、無需金鑰）。可追蹤關注隊伍的即時比分與開賽／完賽通知，並提供戰績榜、賽程、單場數據與賽季走勢分析。
## 程式價值

NBA 賽程、戰績與逐場數據早就是公開資料（ESPN API 免費、無需金鑰），但多數人只會「開瀏覽器搜尋」，做不到「只盯自己那兩隊、只在要緊的那一刻通知我」。這個程式的價值就是把公開資料轉成個人化的通知服務。

### 使用價值

| 日常痛點 | 這個程式的做法 |
| --- | --- |
| 想知道比分都要開瀏覽器搜一遍 | 開機自動啟動、背景自動刷新，關注隊伍自動置頂標記 |
| 比賽開打與完賽常常錯過 | 開賽前 20 分鐘提醒、開打通知、完賽勝負通知 |
| 兩隊支持的球隊撞在一起，不知道算誰贏 | 兩隊都在關注清單時改報對戰結果，不會講錯 |
| 關心的球隊還要自己開分頁查 | 迷你小工具釘在工作角落，可拖曳、雙擊回主視窗 |
| 只看當下比分不夠，想了解整季狀況 | 賽季走勢圖（累積勝率、淨勝分）搭配蒙地卡羅季後賽機率 |
| 開季前、季末沒賽事可看，難以驗證功能 | 示範模式一鍵載入上一季完賽資料，所有功能都跑得起來 |

### 商業價值

* **資料成本為零**：ESPN 公開 API 免費、無金鑰，加上 45～60 秒的 TTL 記憶體快取，請求量等同一般個人使用者
* **部署成本為零**：只用 Python 標準函式庫與 Tkinter，不需 `pip install`，複製資料夾就能執行，適合快速試作與內部工具
* **分層設計讓標的可替換**：`nba_api.py` 只負責抓取與解析，`alerts.py` 只負責狀態比對。換成 CPBL、職棒或任何有公開賽程的聯賽，只需改資料層，通知引擎完全沿用
* **推播本身就是價值**：賽事直播平台、轉播服務與球隊官方 App 都要解決「開賽與完賽要第一時間通知用戶」，這個專案用不到百行就做出不重複、不誤判的版本
* **可衍生的商業場景**：店面的主隊開賽自動開電視、球隊社群的自動賽報圖卡、媒體的賽後戰報自動生成、賽事數據服務的事件驅動
* **展示與教學價值**：從資料抓取、狀態機比對、背景執行緒不卡 UI 到蒙地卡羅模擬，是一個可拆解的軟體工程範例

## 功能總覽

七個分頁：

| 分頁 | 內容 |
|------|------|
| **比分明細** | 指定日期（可前後切換）所有比賽卡片，關注隊伍置頂並標 ★、開賽倒數、「單場數據」按鈕 |
| **單場數據** | 逐人成績（MIN／PTS／FG／3PT／FT／REB／AST／TO／STL／BLK／OREB／DREB／PF／+/-）、球隊總計、單場得分王與場上人數；點欄位標題可排序，合計列固定置頂 |
| **未來賽程** | 未來 N 天（1～14 天）賽程清單，可篩選只看關注隊伍 |
| **球隊戰績** | 全聯盟／東區／西區切換、30 隊戰績含官方隊徽，點欄位標題可排序 |
| **球隊詳情** | 單隊陣容（背號、位置、身高、體重、學院、傷兵狀態）、近期戰績，並可一鍵加入關注；傷兵紅字標示 |
| **賽季走勢** | Canvas 自繪的累積勝率折線與單場淨勝分長條圖，另有晉級季後賽機率 |
| **設定** | 關注隊伍（多選）、通知開關、刷新間隔、開機自動啟動、啟動時縮到背景 |

其他功能：

* **自動刷新**：預設 60 秒更新一次，間隔可調（15～600 秒）
* **Windows 通知**：開賽提醒、開打通知、比賽結果通知（工作列閃爍提醒）
* **迷你比分小工具**：置頂小窗只看關注隊伍，釘在工作角落，可拖曳、雙擊開主視窗
* **高 DPI 適配**：宣告 Per-Monitor V2，4K 投影時字體正常縮放
* **隊徽與分區篩選**：球隊戰績表顯示各隊官方 Logo（背景下載＋本機快取），可切換全聯盟／東區／西區
* **比賽事件（文字直播）**：單場數據下方附逐球事件，最新在前，得分事件標色，可篩選只看得分
* **球員卡**：球隊詳情或單場數據雙擊球員，彈窗顯示大頭照與本季場均（得分／籃板／助攻／命中率等）
* **設定持久化**：`settings.json` 存設定、`state.json` 存已看過的比賽狀態
* **示範模式**：季前／開季前無賽事時，一鍵載入上一季完賽資料試用各功能

## 技術架構

| 層級 | 技術 | 說明 |
|------|------|------|
| 語言 | Python 3.10+ | 只用標準函式庫，**不需 `pip install`** |
| 介面 | `tkinter` + `ttk`（內建於 CPython） | 主視窗七個分頁 + 迷你小工具 |
| 資料來源 | ESPN 公開 API（`site.api.espn.com`） | 免費、無需 API 金鑰 |
| 網路 | `urllib.request` | 20 秒 timeout，失敗包成 `NBAError` |
| 通知 | PowerShell + WinRT Toast | 不需額外套件 |
| 開機啟動 | `winreg` 寫 `HKCU\...\Run` | 不需管理員權限 |

> 需 Windows 10 以上（通知與開機啟動依賴 Windows API），其餘邏輯為跨平台標準函式庫寫法。

## 快速開始

```bash
cd HW3
python main.py
```

或直接雙擊 `啟動.bat`（以 `pythonw.exe` 背景執行，不會跳出黑視窗）。

確認環境：

```bash
python --version    # 需 3.10 以上（用到 `dict | None` 型別註記）
```

首次啟動若沒有 `settings.json`，會自動使用預設值（關注 GS、LAL）並建立檔案。

## 執行測試

兩個測試腳本都會實際連線 ESPN API：

```bash
python 測試_整合.py   # 七項功能逐項整合驗證（含 GUI 互動）
python 測試_邊界.py   # 真實資料下的邊界情況與設定正規化
```

`測試_整合.py` 會建立 Tk 視窗並模擬操作（切換分頁、篩選、開關小工具），執行時會短暫開窗，屬正常現象。


單元測試不需要網路與視窗，push 後由 GitHub Actions 自動執行：

```bash
python -m unittest discover -s tests -v   # alerts／settings／nba_api，共 47 個測試
```
## 離線示範與持續整合

* **離線示範**：先 `python record_demo.py` 把 ESPN 回應錄成 `demo_data/` 快照（約 20 支請求），之後 `python demo_offline.py` 不需網路也能跑完整展示流程，適合課堂發表不斷網
* **單元測試**：`tests/` 用 `unittest` + `mock` 覆蓋通知引擎、設定正規化與資料解析，不需連網，秒級跑完
* **CI 與打包**：`.github/workflows/hw3.yml` 在 push／PR 時自動跑測試；push 到 main 還會用 PyInstaller 打包 Windows exe 並上傳 Artifacts

## 設定檔說明

`settings.json`（壞掉時會自動退回預設值，不會讓程式開不起來）：

| 欄位 | 預設 | 說明 |
|------|------|------|
| `favorites` | `["GS", "LAL"]` | 關注隊伍縮寫，上限 30 筆 |
| `notify_enabled` | `true` | 通知總開關 |
| `notify_tipoff` | `true` | 開賽前提醒 |
| `notify_result` | `true` | 比賽結果通知 |
| `refresh_seconds` | `60` | 刷新間隔，限制 15～600 秒 |
| `preview_days` | `7` | 未來賽程天數，限制 1～14 天 |
| `autostart` | `false` | 開機自動啟動 |
| `start_minimized` | `false` | 啟動時縮到背景 |
| `mini_widget` | `false` | 啟動時開啟迷你小工具 |

寫檔採用「暫存檔 + 置換」，避免程式中途關掉留下半個 JSON。

## 設計與防呆重點

* **不重複通知**：`alerts.detect()` 只認「狀態真的變了」或「第一次進入開賽前 20 分鐘」，同一場比賽不會每次刷新都跳通知
* **平手不誤判**：NBA 加時不會平手，出現平手視為資料異常（通常是其中一隊比分沒抓到），寧可不通知也不報錯的勝負
* **未開賽 ≠ 0 比 0**：ESPN 未開賽時 `score` 是字串 `"0"` 且 `linescores` 為 `null`，用 `has_score` 欄位區分，避免把沒開賽的場次畫成 0-0
* **縮寫正規化**：ESPN 對勇士用 `GS` 而非 `GSW`，`ABBR_ALIASES` 統一處理（`GSW→GS`、`PHO→PHX`、`UTA→UTAH` 等），全部比對前先過 `canon()`
* **欄位範圍收斂**：`settings._normalize()` 在讀寫兩端都做 `_clamp`，非法值退回預設、未知欄位直接丟棄；預設值判斷用 `is None` 而非 falsy，避免 `0` 被當成「沒設定」
* **背景執行緒不卡 UI**：所有 API 請求丟到 worker thread，結果經 `queue.Queue` 由 `_drain()` 在主執行緒取出更新
* **記憶體快取**：`Cache` 類別帶 TTL 與前綴清除，避免切換日期時重複打 API
* **快取不誤蓋**：切換日期時舊回應不回填到新畫面（以日期戳記比對）
* **PowerShell 跳脫**：通知文字以 `_ps()` 包成單引號字面值並將 `'` 轉為 `''`，避免標題含引號時注入
* **API 失敗不中斷**：未知球隊代碼 ESPN 回 400，`season_trend()` / `playoff_probability()` 回空資料讓 UI 顯示提示，而非拋例外
* **季後賽機率**：進行中的賽季以各隊目前勝率當勝率，跑 2000 次蒙地卡羅模擬剩餘賽程；已完賽賽季直接看最終排名
