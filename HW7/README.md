# HW7 — 金門 3D 暗空與光影足跡地圖

> 115 學年上學期｜現代軟體工程 HW7｜國立金門大學資工系｜學號 43

以**單一 `index.html`** 實作的 3D 互動地圖，把金門的暗空景點、拍攝座標與照片 EXIF 疊在同一張可旋轉、可縮放的地形上。不需要後端、不需要建置流程，用瀏覽器打開就能操作。

## 專案簡介

金門的觀星與攝影資訊多半散落在部落格、社群貼文與地圖評論裡，很難一眼看出「哪裡適合拍日出、哪裡光害最低、某張照片是在哪個座標拍的」。這個專案把這些資訊收斂成一個 3D 觀測介面：以真實經緯度投影出金門五個鄉鎮的地形，將預設景點標成光點，點擊後顯示照片、拍攝參數、觀星條件與現場故事。

除了內建的 5 個景點，使用者也可以直接點擊地形新增自己的「光影足跡」：上傳照片後自動讀取 EXIF（相機、鏡頭、光圈、快門、ISO、GPS、拍攝時間），沒有 EXIF 時套用夜拍預設值。所有自訂資料只存在瀏覽器的 LocalStorage，不會上傳到任何伺服器。

## 功能總覽

### 3D 地形與導覽

* 以 Three.js 建立金門島嶼地形，包含金城、金寧、金湖、金沙、烈嶼五個鄉鎮區塊與太武山等山峰起伏
* 鄉鎮名稱、座標 HUD、羅盤、即時時鐘與仿真掃描線／星雲／流星視覺效果
* 滑鼠左鍵旋轉、右鍵平移、滾輪縮放；一鍵重置為鳥瞰視角
* 游標所在位置即時換算 WGS84 經緯度
* 左側「LIGHT TRACE INDEX」可快速點選景點，自動飛行到該座標

### 自訂光影足跡

* 點「新增光影足跡」後直接在地形上點擊放置光點
* 輸入名稱、拖拉或選擇照片，自動讀取 EXIF
* 讀不到 EXIF 時自動套用夜拍預設參數（相機、鏡頭、光圈、快門、ISO）
* 照片壓縮為 JPEG 後與座標一起存入 LocalStorage
* 自訂足跡可從資訊面板刪除；重新整理後仍會保留

### 觀星條件面板

* 依景點緯度、Bortle 等級、雲量與月相計算 0–100 的觀測分數
* 顯示 Bortle 1–9 等級尺標、雲量百分比、月相照明百分比與觀測評語
* 面板包含照片、GPS、拍攝參數、主題標籤與現場故事

## 技術架構

| 類別 | 技術 | 說明 |
| --- | --- | --- |
| 3D 渲染 | Three.js r160（CDN import map） | 地形、光點、星空、 raycasting 點擊 |
| 相機控制 | `OrbitControls` | 旋轉、平移、縮放、飛行至景點 |
| 樣式 | Tailwind CSS（CDN）＋原生 CSS | 玻璃擬態面板、HUD、響應式排版 |
| 動畫 | GSAP 3.12 | 進場與面板動畫 |
| EXIF | exif-js 2.3 | 讀取相機、鏡頭、曝光、GPS、日期 |
| 儲存 | LocalStorage | `kinmen_light_traces_v1`，只存於本機瀏覽器 |
| 字型 | Google Fonts | Space Grotesk／Noto Sans TC／JetBrains Mono |

> 全部透過 CDN 載入，沒有 `package.json`、沒有 bundler、沒有後端。

## 快速開始

### 方式一：直接開啟

在檔案總管雙擊 `HW7/index.html`，或用瀏覽器開啟即可。

### 方式二：本機靜態伺服器（建議）

部分瀏覽器對 `file://` 的 CDN 與 Canvas 行為較嚴格，建議用簡單靜態伺服器：

```bash
cd HW7
python -m http.server 8080
```

開啟 <http://localhost:8080>。

### 環境需求

* 支援 WebGL 的現代瀏覽器（Chrome／Edge／Firefox／Safari）
* 需要網路連線載入 Three.js、Tailwind、GSAP、exif-js 與字型 CDN

## 操作方式

1. **瀏覽景點**：點擊地圖上的光點，或從左側清單選擇，資訊面板會從右側展開
2. **新增足跡**：按右上「新增光影足跡」→ 在地形上點擊位置 → 輸入名稱並上傳照片 → 儲存
3. **查看拍攝資訊**：資訊面板會顯示 EXIF、GPS、觀測分數與故事
4. **刪除自訂足跡**：開啟該足跡後，按面板底部的「移除此自訂光影足跡」
5. **重置視角**：按右上角十字準星圖示回到鳥瞰視角

## 資料儲存與隱私

* 自訂足跡（名稱、座標、照片、EXIF）只寫入瀏覽器 LocalStorage
* 照片會先壓縮為 JPEG 再儲存，避免佔用過多空間
* 清除網站資料或更換瀏覽器後，自訂足跡會消失
* 專案沒有任何後端請求，也不會把照片上傳到第三方

## 設計重點

* **經緯度投影**：以金門中心點（24.4575°N, 118.3425°E）換算公尺尺度，將 WGS84 座標投影到 Three.js 的 XZ 平面，點擊地形時再反向換算回經緯度
* **程序化照片**：內建景點沒有使用外部照片，而是依主題（日出、夕陽、星空、潮汐、街拍）與景點名稱用 Canvas 產生對應色溫與構圖，避免圖片授權問題
* **EXIF 防呆**：GPS 與拍攝時間格式不一致時會先驗證；缺欄位時退回夜拍預設值，不讓面板出現空白
* **LocalStorage 驗證**：讀取時逐筆檢查型別與照片格式，損壞資料會被忽略而不是讓整個地圖壞掉
* **效能**：裝置像素比上限 2、降低動畫移動量（`prefers-reduced-motion`）、只有需要時才更新 raycasting
* **可及性**：面板與按鈕有 `aria-label`／`aria-live`，資訊面板開啟時同步更新 `aria-hidden`
